# Galaxy on Fire 2 HD — Mod (Android)

Mod para **Galaxy on Fire 2 HD** (`net.fishlabs.gof2hdallandroid2012`), feito por VSFLima.

> Este repositório contém os arquivos necessários para jogar a versão modificada: o **APK com o mod**, o **APK original** (base) e o **OBB** (dados do jogo).

---

## Conteúdo do mod

### Combate
- **God Mode** — a sua nave (e a god-mode geral) não sofre dano.
- **Armas primárias com dano alto** — todas as armas primárias causam **10000** de dano por tiro.
- **Míssil Liberator** — dano **999999** (destrói qualquer nave).
- **Recarga / velocidade / rotação das armas** — mantidas no padrão.

### Naves
- **Todas as naves disponíveis para compra** em qualquer estação.
- **Spectre melhorada** — atributos (HP, carga, slots, handling) elevados.

### Economia / Estação
- **Todos os itens em todas as estações.**
- **Compra infinita** — o estoque da loja nunca esgota.
- **Créditos** — dinheiro fixo alto no início.

### Progressão
- **Todos os sistemas solares liberados** (visíveis e descobertos).
- **Todas as blueprints** desbloqueadas.

### Jogabilidade
- **Sem tela preta do booster / câmera lenta** (corrigido).
- **Todos os mods ativos** nas três campanhas: **Galaxy on Fire 2 (base)**, **DLC Valkyrie** e **DLC Supernova**.

## Arquivos

| Arquivo | Descrição |
|---|---|
| `apk/GOF2FHD_MOD.apk` | APK com o mod aplicado. **Instale este.** |
| `apk/GOF2FHD_Original.apk` | APK original (sem mod) — usado apenas como base. |
| **OBB** (`main.47947006.net.fishlabs.gof2hdallandroid2012.obb`) | Dados do jogo (texturas, modelos, áudio). Necessário para o jogo rodar. Disponível na aba **Releases** (é grande, ~1,4 GB). |

---

## Instalação

1. **Desinstale** qualquer versão anterior do Galaxy on Fire 2 HD.
2. Instale o `GOF2FHD_MOD.apk`.
3. Baixe o **OBB** na aba **Releases** deste repositório.
4. Coloque o OBB em:

   ```
   Android/obb/net.fishlabs.gof2hdallandroid2012/main.47947006.net.fishlabs.gof2hdallandroid2012.obb
   ```

5. Abra o jogo e divirta-se.

> Se você já tem o jogo original instalado, basta substituir o APK pelo modificado, mantendo o OBB no lugar.

---

## Observações

- Este é um mod **offline**, apenas para uso pessoal. Use por sua conta e risco.
- O OBB é o **arquivo de dados** do jogo. Sem ele o jogo não abre.
- As modificações de dados (naves, itens, armas) ficam no **APK** e no **OBB**.
